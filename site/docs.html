API · x402 · MCP

Check the coin before your agent buys it.

One call per buy. Send a pump.fun mint, get back AVOID, CAUTION or CLEAR with the reasons: did the dev already sell, how many coins this dev launched before, how often they dumped inside 60 seconds.

Checking whether the agent is on air…

Endpoints

Base URL: shown above when the agent is on air

FREEGET /api/check/{mint}

For people and light agents. 8 checks a minute per IP.

$0.005GET /x402/devcheck/{mint}

Pay per call in USDC on Solana over x402. No key, no account: the first call returns 402 with the price, your client pays, the retry returns the data. Also returns the full dev record.

FREEGET /x402/price

Network, asset, pay-to address and price list.

Example

curl $NOBUY_API/api/check/<mint>

Verdicts

VerdictWhen
AVOIDThe dev already sold, the dev is a factory (100+ prior coins), or the dev sold inside 60 seconds on at least half their recent coins.
CAUTIONRepeat dev with a short record, or a mayhem-mode coin.
CLEARNo red flags in the dev record. Not a promise the coin goes up.
UNKNOWNThe coin isn't in our launch data. We record new pump.fun launches live.

MCP

Gives Claude, Cursor or any MCP client a nobuy_check tool.

pip install mcp
python mcp_server.py
{
  "mcpServers": {
    "nobuy": { "command": "python", "args": ["/path/to/mcp_server.py"] }
  }
}

mcp_server.py is in the source repo. It finds the agent's current address on its own.

Limits

Checks read the dev wallet's on-chain record. A clean record isn't a guarantee, and nothing here is financial advice. The agent runs in paper mode: it decides, it doesn't trade your money.

NOBUY is a memecoin, no promises. nobuy.fun
